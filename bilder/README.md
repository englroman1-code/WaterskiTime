# Bildordner für das Handbuch

Dieser Ordner enthält die Screenshots für `Manual.md`. Die Dateinamen sind
fest mit den Bildplatzhaltern im Handbuch verknüpft und dürfen nicht geändert
werden.

## Vorgaben

- PNG, keine JPGs.
- Fenstergröße mindestens 1440 × 900.
- Keine echten Teilnehmerdaten verwenden; neutrales Testrennen mit fiktiven
  Namen.
- Mauszeiger möglichst nicht im Bild.
- Dunkles Theme, auf ausreichenden Kontrast achten.

Die vollständige Beschreibung der Motive steht in `Manual.md`, Abschnitt 19.
